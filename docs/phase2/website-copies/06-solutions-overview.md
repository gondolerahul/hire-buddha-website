## Section 6 · THE ADOPTION PATH

**Eyebrow:**
`HOW TO START`

**Section Headline:**
You don't reorganize into the loop. You deploy into it.

**The Path (6 phases):**

**Phase 0 — Meet:** Talk to Pragya. Describe your business, your goals, and your pain points.

**Phase 1 — Ingest:** Pragya ingests your knowledge base — files, SharePoint, Notion, Drive, databases.

**Phase 2 — Connect:** Connect your existing systems — CRM, ERP, accounting, HRMS, invoicing, telephony.

**Phase 3 — Model:** The dynamic schema seeds entities. Map your departments to arcs using the blueprint.

**Phase 4 — Deploy:** Deploy agent templates or have the Meta Agent build the missing ones.

**Phase 5 — Run & Evolve:** The loop runs 24/7. The Learning System tunes it. Pragya reports. Humans handle HITL.

**Adoption Pattern:**
> Start with one high-ROI Process — typically Cold-to-Closed Acquisition or Order-to-Cash. Prove it inside the loop. Then let the shared memory and the Learning System pull the adjacent arcs in. Because everything shares the axle, each new Process you add makes the existing ones smarter — the opposite of bolting on another silo.
