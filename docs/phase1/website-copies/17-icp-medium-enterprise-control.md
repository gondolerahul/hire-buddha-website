## Section 2: The Governance Stack

### Six layers of control. Zero blind spots.

**Layer 1: Credit Circuit Breaker**
Automatic execution halt if cost exceeds your budget. Set at the process, agent, or action level. No runaway spend — ever.

**Layer 2: Human-in-the-Loop Checkpoints**
Pause before high-stakes actions. Configurable per agent, per action, per loop. Notifications arrive in Slack, Teams, or email with one-click approve/reject.

**Layer 3: Pre-Critic Audit**
The AI audits its own decisions BEFORE execution. If the Pre-Critic blocks 3 consecutive actions, the circuit breaker trips — execution halts and escalates to a human. Your AI workforce has a built-in quality gate.

**Layer 4: Post-Critic Supervision**
After execution, the supervisor checks alignment with the original goal. Logs token usage, cost, and latency. Schedules retries if needed.

**Layer 5: Full Audit Trail**
Every run traced: tokens consumed, tools invoked, cost attributed, decisions logged with reasoning chains. Exportable as CSV or JSON for compliance reporting.

**Layer 6: Company Suspension Middleware**
Emergency kill switch. Instant API lockout if needed. Active executions halt. No data deleted. Reactivation restores full access.

## Section 3: HITL in Practice

### Real-world governance rules from real deployments.

| Scenario | HITL Rule | What Happens |
|---|---|---|
| Outbound email to a prospect valued over ₹40 lakh | Pause before sending | Agent drafts the email → notification in Slack → manager reviews → approve/reject/modify → send or discard |
| Payout exceeding ₹50,000 | Pause before processing | Treasury Controller prepares the payment → HITL notification → finance head reviews → approves → payment processed |
| Contract with risk score above 6/10 | Pause before routing for signature | Contract Sentinel flags the issues → full analysis attached → legal reviews → approves, rejects, or requests changes |
| Customer sentiment drops below 0.3 during a call | Alert and optional escalation | Care Orchestrator flags the conversation → human agent can join the call or take over |
| Auto-tuning recommendation from Intelligence Engine | Approve before applying | Intelligence Engine proposes a change to agent settings → operations lead reviews → approves or defers |
