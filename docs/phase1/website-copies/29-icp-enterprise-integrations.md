## Section 3: Custom Tool Builder

### Don't see your system? Build a custom integration.

HireBuddha's tool registry is extensible. Register any API as a custom tool:

1. **Define the endpoint** — URL, HTTP method, authentication type
2. **Set the schema** — Input parameters and output structure
3. **Register in the tool registry** — The tool becomes available to bind to any AI Employee
4. **Deploy** — Your custom tool works exactly like a built-in one

**Pragya can help:** Describe the system you need to connect to, and Pragya will architect the custom tool specification.
