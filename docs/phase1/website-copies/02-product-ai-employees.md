## Section 2: The 4-Tier Hierarchy

**Psychological Principle:** *Structured Authority + Organizational Metaphor.* By mapping AI architecture to familiar business roles (CEO → Manager → Specialist → Worker), we make complex technology instantly intuitive. The visitor thinks: "I already understand how to structure this."

### A workforce structure your business already understands.

HireBuddha organizes AI Employees into the same hierarchy that runs every successful company. Each tier does what it's built for — strategy stays at the top, execution stays at the bottom, and nothing falls through the cracks.

---

#### Tier 1: Process — The C-Suite Orchestrator

**Role analogy:** CEO / VP

Coordinates multi-department workflows. Receives high-level goals ("Reactivate stale Q1 leads"), generates a dynamic execution plan, dispatches child agents across departments, handles parallel branches and conditional routing, and summarizes final business outcomes.

**What it does:**
- Runs DAG-based execution plans with parallel branches
- Dispatches child agents and merges their results
- Tracks cross-department costs and performance
- Generates end-to-end outcome reports

**Example:** "Run our quarterly lead nurture campaign across sales, support, and marketing — then report on conversion and cost."

---

#### Tier 2: Agent — The Manager

**Role analogy:** Sales Manager / Support Lead

Manages a specific communication channel or domain. Maintains conversational state across interactions. Applies domain guidelines. Routes complex requests to specialists. Remembers every customer it has ever spoken to.

**What it does:**
- Holds real-time voice and text conversations
- Maintains episodic memory across customer interactions
- Routes complex cases to Skills and Actions
- Applies personality settings (tone, empathy, formality)

**Example:** "Sarah" — your Outbound Sales Agent. She calls prospects, qualifies interest, books demos, and sends follow-up emails — all in your brand's voice.

---

#### Tier 3: Skill — The Specialist

**Role analogy:** Contract Specialist / Data Analyst

Executes a focused technical task — document generation, data analysis, template processing. Operates with surgical precision. No conversation, no small talk — just results.

**What it does:**
- Generates PDFs, Excel reports, Word documents, and presentations
- Runs data analysis in sandboxed Python environments
- Processes templates with dynamic variables
- Delivers outputs via email, webhook, or file

**Example:** The "Smart Proposal" Skill takes customer data, runs ROI calculations, generates a branded PDF proposal, and routes it for e-signature — all in under 60 seconds.

---

#### Tier 4: Action — The Worker

**Role analogy:** API Caller / Tool Operator

Atomic, tool-assisted execution. The interface between AI and external systems. Calls an API, reads a database, sends an email, scrapes a webpage. One task. One tool. One result.

**What it does:**
- Calls registered tools (web search, email send, API call)
- Validates inputs and handles timeouts
- Reports structured outputs to the parent Skill or Agent
- Tracks execution cost and latency

**Example:** "Query Salesforce for Company ID" or "Send payment reminder via WhatsApp."

**7. Governance**

**8. I/O Contract**

## Section 4: Execution Reasoning Modes

**Psychological Principle:** *Technical Specificity = Trust.* Enterprise evaluators and technical founders trust products that can explain *how* they work, not just *what* they do. This section survives CTO scrutiny.

### Two modes of reasoning. Choose per task.

**ReAct (Reason-then-Act)**

The agent decides which tool to call, runs the tool, observes the results, and loops until the task is complete.

Best for:
- Database queries and CRM operations
- Email triage and response
- Linear, sequential workflows
- Real-time voice conversations

**Chain-of-Thought (CoT)**

The agent writes out its step-by-step logic explicitly before generating final outputs. Slower, but more reliable for complex reasoning.

Best for:
- Document drafting and legal review
- Financial analysis and reconciliation
- Complex multi-variable calculations
- Strategic planning and briefing generation

**VISUAL DIRECTION:** Side-by-side comparison of the same task ("Draft a proposal for a $50K contract") solved with ReAct (direct, fast, tool-heavy) vs. CoT (deliberate, reasoned, structured output).
