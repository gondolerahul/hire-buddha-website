## SECTION 3 — The 4-Tier Memory System

**Principle:** *Analogy-driven comprehension.* Desk → conversation history → filing cabinet → institutional memory makes an abstract architecture instantly intuitive, and the last tier sets up the compounding payoff.

## Most AI forgets. Yours remembers – on four levels.

| Tier | Name | What it holds | Like… |
|---|---|---|---|
| 1 | **Working Memory** | The scratchpad for the current task: inputs, metrics, step calculations. | Your desk – today's work, in front of you. |
| 2 | **Episodic Memory** | The last 10 interactions per contact. Conversational continuity. | "We spoke about this last Tuesday." |
| 3 | **Semantic Memory** | Vector search over every document you've uploaded. RAG retrieval by meaning. | A filing cabinet where everything is searchable by what it *means*. |
| 4 | **CORTEX Tree Memory** | Hierarchical cognitive context for long-running work. Auto-checkpointing. | Institutional memory – the deep context that makes Week 12 smarter than Week 1. |

**Inside CORTEX:**
- A node hierarchy: root → knowledge → finding → task → output → checkpoint.
- Auto-checkpointing: when context approaches 8,000 tokens, it summarizes and preserves progress.
- Viewport slicing: the perceiver pulls only the relevant path from the tree, so the AI never hits a context-window wall.

**Key message:** CORTEX is *why* your workforce gets better the longer it runs. Every interaction, decision, and reflection is stored and compounded.

## SECTION 4 — The AgentLoop

**Principle:** *Trust through self-regulation.* The deepest AI fear is "it'll act wrong and I won't know." Showing a worker that critiques itself *before and after* every action converts that fear into confidence.

## This isn't if-then automation. It's deliberative cognition.

Every AI Employee runs an 8-stage loop on every step – a full reasoning cycle with quality control built in:

`Perceive → Strategize → Pre-Critic → Act → Observe → Post-Critic → Reflect → Decide`

1. **Perceive** – load inputs, semantic chunks, and context for this step.
2. **Strategize** – choose the next action or call the planner.
3. **Pre-Critic** *(safety gate)* – audit the action *before* it runs. Three consecutive blocks trip a circuit breaker and halt execution.
4. **Act** – execute the step.
5. **Observe** – process outputs; catch errors and runtime blocks.
6. **Post-Critic** *(quality check)* – verify alignment with the goal, log usage, schedule retries.
7. **Reflect** – write a logical reflection back to CORTEX. This feeds the Learning System.
8. **Decide** – CONTINUE, REPLAN, DONE, or ABORT.

**Key message:** The Pre-Critic catches mistakes before they happen. The Post-Critic catches drift before it compounds. CORTEX stores the lesson. Your workforce audits its own decisions on both sides of every action.
