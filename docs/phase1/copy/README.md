## Conventions
- **`{{token}}`** = a placeholder for a real number/name not yet available. Never ship a fabricated metric, logo, or customer.
- **No em-dashes in production copy** (per the UI/UX audit). These internal docs use them freely; the copy lines themselves do not.
- The universal spine across every page: **Stop Hiring. Start Deploying.** → the four pillars → Pragya as proof.
